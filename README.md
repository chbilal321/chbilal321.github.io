# chbilal321.github.io

Personal academic website of Bilal Shaker, PhD. It's served by GitHub Pages at https://chbilal321.github.io.

Plain HTML, CSS and JavaScript with no build step.

- `index.html`: page content
- `js/data.js`: publication list (update citation counts here)
- `js/figures.js`: live animations (MD, diffusion, classifier, multi-omics, BBB)
- `assets/photo.jpg`: optional portrait; if it's present it replaces the "BS" monogram
- `assets/Bilal_Shaker_CV.pdf`: downloadable CV
